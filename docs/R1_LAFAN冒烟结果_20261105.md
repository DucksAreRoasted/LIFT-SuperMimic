# R1＋LAFAN 冒烟测试实测

2026-11-05，经用户明确允许，在本地 RTX 5070 Laptop 8 GB 上完成原 SuperMimic 与固定双梯度的短训练。两组正常退出，采集、WM 更新、Actor 更新、统一评估、检查点和汇总均完成。当前可以开始服务器上的小规模继续训练实验；尚不能据此评价长期收敛或算法优劣。

## 数据和起点

- 复用旧仓库 `lafan1_modelscope_v1/r1`，已复制至当前项目 `data/retarget/lafan1_modelscope_v1/r1/`。
- 40 段、441,140 帧、50 Hz、26 个 R1 关节。导入脚本已对全部片段执行结构、数值及关节顺序检查，并写入逐文件哈希清单。
- 复用 `r1_lafan1/ckpt_latest.pt`，复制至 `data/checkpoints/r1_supermimic_pretrained.pt`。没有重新做预训练。
- 冒烟仅使用 `walk1_subject1`；未对全部 40 段执行训练。没有划分未见动作测试集。

## 实际运行配置

配置：[r1_lafan1_smoke.json](../configs/experiments/r1_lafan1_smoke.json)。16 个并行环境、48 次环境步、20 步预热、Actor／WM batch 16、想象时域 4，关闭 Torch compile。种子 0，评估在第 0／24／48 步执行，每次 20 步封顶。

实际调用本 workspace 的 `.venv/bin/python scripts/run_suite.py`，训练参数如下；服务器可通过 uv 重复：

```bash
uv run --extra train --locked python scripts/run_suite.py \
  --checkpoint data/checkpoints/r1_supermimic_pretrained.pt \
  --motions data/retarget/lafan1_modelscope_v1/r1 \
  --protocol configs/experiments/r1_lafan1_smoke.json \
  --methods supermimic dual_fixed --seeds 0 \
  --output outputs/r1_smoke_server_01
```

耗时不含加载检查点前的阶段，首次内核缓存状态也不同，不用于计算性能比较。两组最终评估均未在这 20 步内摔倒，且都触发评估封顶，不能称为完成整段动作。

双梯度 11 次更新的 Q 梯度范数为 0.1273～0.2131，动力学梯度范数为 0.4922～0.7553，梯度余弦为 0.1608～0.5952，Q loss 为 0.00106～0.00733，均为有限数值。逐项读取最终检查点确认参数有限，两个分支的均值 Actor 各有 20 个张量发生变化，世界模型各有 14 个张量发生变化。

本轮数值测试与数据发布／下载命令测试共 7 项通过。下载命令只做了隔离环境与 R1 参数传递的模拟测试，未重新联网下载或执行 IK；实际数据来自已有复现结果。
