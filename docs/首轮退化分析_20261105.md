# R1／LAFAN 首轮继续训练退化分析

日期：2026-11-05。适用代码：服务器首轮实验提交 `7d6bd71`。

依据：服务器四组 seed 0、各 5,000 步的完整评估，以及 `events.jsonl`、实际配置和更新源码。逐更新摘录保存在本地 `outputs/server_results_20261105/failure_diagnostics.json`。本轮只分析，没有启动新训练，也未修改训练算法。

**当前证据更支持继续训练设置和新增训练路径失稳，不能据此否定可信双梯度方向。** 以下区分代码中确定的改变、日志观察和仍需受控实验验证的因果解释。

最需要修正的三件事是：建立稳定的原基线继续训练配置；将成熟 Actor 与冷启动 Q 隔离；恢复“均值 BPTT＋原 V 引导＋固定方差”的最小起步路径。终止标记错位是已复现的代码错误，应先修正。梯度冲突与尺度校准则在单分支稳定之后再处理。

**实验范围与结果。**

平台为 mjlab／MuJoCo Warp／PyTorch，机器人为宇树 R1。数据来自 ModelScope 的 `AI-ModelScope/LAFAN1_Retargeting_Dataset`，重定向后共 40 段、441,140 帧、50 Hz。四组共用第 51,350 步的原生 SuperMimic 预训练检查点，每组继续训练 5,000 个向量环境步、256 环境，即 128 万条训练交互；每组完成 1,984 次 Actor 更新。

四组均正常退出，最终模型和日志已保存。本轮是单种子、同一批动作上的继续训练比较，没有验证未见动作泛化，也没有实现可信度门控或自适应时域。

| 方法 | 初始平均参考完成比例 | 1,000 步 | 5,000 步 | 最终失败片段 | 最终平均存活时长 |
|---|---:|---:|---:|---:|---:|
| SuperMimic | 92.51% | 10.48% | 57.73% | 27/40 | 134.493 s |
| Q only | 92.55% | 0.63% | 0.24% | 40/40 | 0.505 s |
| BPTT soft | 94.47% | 0.52% | 0.40% | 40/40 | 0.829 s |
| Dual fixed | 94.47% | 0.43% | 0.40% | 40/40 | 0.823 s |

“平均参考完成比例”是逐片段已执行步数占参考长度的比例再取平均，不是成功片段比例。均值策略执行完整动作评估，未设置步数封顶。

新分支在首次定期评估前已经退化；后面继续训练没有恢复。所有组初始均值策略仍能跟踪大部分动作，因此首先应定位更新过程。初始结果略有差异，现有数据不能将其当成各组严格逐帧一致的证明。

**1. 原基线也没有建立稳定的继续训练对照。**

`src/tadg/experiment.py:33` 加载预训练网络后，覆盖了大量原训练参数：

| 设置 | 原复现配置 | 首轮对照 |
|---|---:|---:|
| 并行环境 | 4,096 | 256 |
| Actor batch | 2,048 | 256 |
| WM batch | 2,048 | 256 |
| 每次 Actor 更新对应 WM 批次数 | 10 | 2 |
| BPTT 时域 | 32 | 8 |
| 每个环境 replay 行数 | 1,000 | 300 |

此外，Actor／WM／V 的 Adam 状态没有恢复，返回采样器重置，学习率调度从 0 按 5,000 步重新计算。它保留了原更新代码，但不是原生训练过程的无缝续跑。

WM／Actor 的批次数比例从 10:1 变成 2:1，模型拟合与策略改进的配比改变。环境数减少 16 倍而每个向量步的更新次数保持不变，意味着每条真实转移对应的优化器更新次数增多；考虑 batch 同时缩小后，不能直接称为所有样本复用量都增加 16 倍。

确定结论是对照配置改变过多，且原分支确实退化。哪一项贡献最大，目前不能排序成已证实因果。

**2. 三个新分支都从第一次 Actor 更新起使用冷启动 Q。**

`src/tadg/trainer.py:47` 创建新的 TwinQ，`trainer.py:113` 只加载预训练均值 Actor 和 WM。首轮没有预热 Q 的独立阶段：40 个向量步填充 replay 后，每次只进行一次 Q 更新，随后立即更新 Actor。

Q only 直接用这个 Q 的动作导数更新成熟 Actor；BPTT soft 和 Dual fixed 在想象末端也使用新 Q，见 `src/tadg/imagination.py:54`。因此 **BPTT soft 并不是保持原 SuperMimic 末端 V 的单分支对照**。它的失败无法独立证明动力学梯度失效，也可能受共同 Q 接口影响。

原分支第一次记录的想象目标约 8.17，新 BPTT 约 0.58；两者同时改变了末端值和目标定义，不能直接横比数值，也不能称为只增加了一个方差头。

这是高优先级的机制风险，但仍需“保留旧 V／预热新 Q”的分离实验确认贡献。

**3. BPTT 同时改成随机动作，并开始优化方差。**

`src/tadg/imagination.py:36` 在每一步调用重参数化随机采样，`gradients.py:13` 对全部 Actor 参数求梯度，方差头也在其中。这与最初更保守的“BPTT 使用均值动作，方差先固定”起步方案不同。

日志直接显示探索分布快速变化：

- Q only：第 42 步标准差均值 0.100；第 89 步约 0.939；第 289 步约 2.275。
- Q only 第 89 步采样动作绝对值最大约 271，第 289 步约 929。
- Dual fixed 标准差从约 0.100 增至约 0.35；想象动作绝对值最大值后期达到数百。

这些动作量是归一化关节目标，不能当成弧度；BPTT 分支的动作统计来自想象轨迹，也不能说所有这些极端动作都在真实仿真中执行过。

代码使用无 tanh 高斯动作，方差允许达到 `exp(1)`，没有约束策略偏离预训练均值。日志与“冷 Q／新目标推动策略偏移，探索变大，采集分布和模型输入随之偏移”的失稳闭环相符。因果强度仍需冻结方差的对照确认。

还有一个接口变化：原环境额外执行噪声不进入 clean action 历史；新随机分支把采样动作作为 raw action，因此动作历史和 action-rate 惩罚的语义也发生变化。相同的初始噪声标准差不保证与旧采集方式等价。

当前完整评估本来就使用均值动作，所以退化不能仅靠部署时去掉采样解决，均值策略本身也已改变。

**4. 想象目标改善与真实任务表现出现背离。**

Dual fixed 的日志：

| 量 | 第 42 步 | 第 4,999 步 |
|---|---:|---:|
| 想象平均即时奖励 | 0.07386 | 0.01479 |
| 想象 soft 目标 | 0.58008 | 1.32545 |
| Q actor 目标 | 0.17742 | 1.23872 |
| 想象动作绝对值均值 | 1.70972 | 14.03557 |

目标上升同时即时奖励下降，真实评估平均约 0.82 秒便失败。这符合“价值估计／模型梯度被策略利用”的风险特征，但不能只靠这些量断言 Q 的精确高估量，现有日志没有单独记录末端值、熵和加权奖励的完整分解，也没有真实 Monte Carlo Q 校准。

Q only 的 WM 一步 NSE 从首次约 0.0267 增至第 289 步约 2.07，同时方差和动作幅度早已明显增大。这是策略—数据—模型闭环失稳的证据，不能把后期 WM 误差全当成最初的诱因。

**5. 固定 0.5 没有形成经过校准的梯度融合。**

Dual fixed 共 1,984 次 Actor 更新，其中约 **93.30%** 的梯度余弦为负；前 100 次更新中约 83% 为负。余弦中位数约 -0.413，动力学／Q 梯度范数比中位数约 **2.69**。

所以两个系数各 0.5，不等于两个梯度贡献均衡。代码也没有进行范数匹配或冲突控制。高冲突率本身不能判断哪一条梯度正确。

另一个实现差异是原 Actor 使用 `-J/H` 并做范数与逐元素裁剪，新分支没有 `/H` 且只做范数裁剪。由于 Adam、熵、末端 Q 和裁剪同时存在，不能简单说实际参数步长因此放大 8 倍；可以确定的是两个分支的相对尺度与原来的裁剪行为没有对齐。

**6. 确认存在终止标记读取错位。**

Recorder 在当前转移行写入本次动作是否导致终止，又额外写入 terminal 状态行，见 `baselines/supermimic/src/supermimic/data/recorder.py:70`。但 SAC bootstrap 读取 `buffer.done[env, next_time]`，见 `src/tadg/experience.py:90`。

CPU 最小复现：`s0 → s1` 尚未终止，下一条 `s1 → s2` 才摔倒。当前实现为第一条转移读到下一行的 done=1，把本应为 1 的 bootstrap 错设为 0。最后一条终止转移则恰好也能读到 terminal 行的 1。

这是需要修正的实现错误。原 WM 采样也按下一行读取终止标签，修正时应统一 buffer 中“转移终止”与“状态终止”的语义。尚不能量化此错误对总退化的贡献，不能把所有问题归咎于它。

**后续修改应先恢复可解释的最小路径。**

先修正终止语义并建立稳定的原基线继续训练配置；然后保留原均值 BPTT、原 V 引导和固定方差，单独接入随机采集；再预热／初始化 Q，最后逐步引入 Q 梯度和尺度校准。这样才能分别判断哪个接口开始破坏已学会的模仿能力。此处没有启动这些新实验。

| 修改顺序 | 具体代码改动方向 | 要独立回答的问题 |
|---|---|---|
| 1 | 统一 recorder、replay、SAC、WM 的终止标签语义，保留终止前实际下一状态 | 转移目标是否正确，是否提前关闭 bootstrap |
| 2 | 在 `experiment.py` 中分开“恢复原训练”与“缩小预算微调”；明确优化器、学习率、采样器的恢复方式，重新设置 WM／Actor 更新配比 | 原 SuperMimic 在这套继续训练设置下能否保住原有能力 |
| 3 | 复用原均值 BPTT 和 V critic；方差先固定，随机采集单独开关；明确历史动作与平滑惩罚的语义 | 随机 Actor 接口本身是否引入退化 |
| 4 | Actor 暂停更新期间预热 Q，或利用旧 V 构造一致的 Q 初始化目标；开始阶段保留 V 末端引导 | Q 接入是否损坏已有策略，何时具备指导 Actor 的条件 |
| 5 | 记录并分解即时奖励、熵、末端值；对齐目标尺度、裁剪与两支梯度的相对范数，再引入渐增融合权重 | 融合收益是否来自两条有效梯度，而非某一分支数值占优 |

这些是后续修改方向，不是本轮已经验证有效的修复。特别是梯度投影、可信度和自适应时域，都不能替代对错误目标、冷启动 Q 和不稳定单分支的修正。
